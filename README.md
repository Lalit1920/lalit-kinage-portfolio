## 📝 Description

This is my personal portfolio website built with React.js and Three.js, featuring interactive 3D elements and smooth animations. The portfolio showcases my professional experience, projects, and technical skills in an engaging and modern interface.

## ✨ Technologies Used

- **Frontend**: React.js, TypeScript, Three.js
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **3D Graphics**: Three.js, React Three Fiber
- **Build Tool**: Vite
- **Email Service**: EmailJS
- **Deployment**: Vercel

## 🚀 Features

- Interactive 3D computer model
- Smooth animations and transitions
- Responsive design for all devices
- Contact form with email integration
- Project showcase with live demos
- Professional experience timeline
- Skills and certifications display

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/lalit-kinage-portfolio.git
```

2. Navigate to the project directory:
```bash
cd lalit-kinage-portfolio
```

3. Install dependencies:
```bash
npm install
```

4. Create a `.env` file and add your EmailJS credentials:
```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAIL_JS_ACCESS_TOKEN=your_access_token
```

5. Start the development server:
```bash
npm run dev
```
